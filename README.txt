HOW TO PUBLISH ON GITHUB PAGES
1. Extract this ZIP.
2. In the GitHub repository, remove/replace the old website files.
3. Upload index.html, style.css, script.js and the whole assets folder.
4. Keep assets folder in the repository root.
5. Settings -> Pages -> Deploy from branch -> main -> / (root) -> Save.
6. Wait for deployment, then open the Pages URL.

NOTE ABOUT THE URL:
A GitHub project site under username 'jaggu-fode' will normally have the form:
https://jaggu-fode.github.io/tushar-anjali.github.io/
A clean URL like https://tushar-anjali.github.io requires a GitHub account/user site using the username 'tushar-anjali', or use a custom domain.
